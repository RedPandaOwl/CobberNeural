# CobberNeural

This is a project for a Neural Networks class. This project is being made by Tommy Philaya, Avery Litke, and Triet Mihn Pham.

This project uses Minnesota and Indonesian weather data to make predictions about how the two different data sets relate when it comes to training neural networks.

Setup:
install the required python libraries

python -m pip install pandas numpy scikit-learn tensorflow

Place a .csv with weather data in the project folder and run.
